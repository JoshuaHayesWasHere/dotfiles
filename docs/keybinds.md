# Keybinds

Generated from the running compositor by `config/hypr/scripts/keybinds markdown`.
Do not edit by hand: change `config/hypr/binds.lua`, then regenerate with

```sh
~/.config/hypr/scripts/keybinds markdown > ~/dotfiles/docs/keybinds.md
```
